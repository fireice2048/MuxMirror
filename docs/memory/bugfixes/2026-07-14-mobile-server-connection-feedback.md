# BugFix 记忆：移动端服务器连接失败的反馈与返回

## 现象

- 触发条件：在服务器列表中打开不可用地址，或地址未运行 Attach 服务。
- 用户影响：连接失败被显示为“服务器暂无终端窗口”；对不可达地址会长期停留在加载页，页面没有应用内返回入口。

## 根因

- `AttachApp` 捕获 `listWindows` 的所有异常后，用空窗口列表作为默认结果，丢失了连接失败语义。
- 连接中的页面只显示加载文字，未提供修改状态并返回服务器列表的按钮。
- 请求没有上层超时约束，网络连接等待时间不可控。

## 修复方案

- 涉及模块：`MobileClient/composeUI`。
- 关键改动：为窗口列表请求增加 10 秒超时；保存并展示连接错误；加载/错误页面均提供“返回服务器列表”按钮。

## 验证方式

- 复现步骤：分别打开未运行 Attach 服务的地址与不可达地址。
- 验证命令：重新构建 HarmonyOS `entry` 模块并在模拟器操作服务器列表。
- 验证结果：`./gradlew :composeUI:publishDebugBinariesToHarmonyApp` 与 `devecocli build --modules entry` 均成功；已安装并启动到 Pura 90 Pro 模拟器，应用进程保持运行。需在模拟器中分别点击两个条目，确认错误提示与返回按钮的交互结果。

## 预防措施

- 不要将通信或协议异常转换成空业务数据。
- 所有可等待的远程资源页都应有超时、错误文案和应用内返回路径。
