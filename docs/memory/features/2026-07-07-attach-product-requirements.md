# 功能记忆：Attach 终端增强工具需求

## 背景

- 需求来源：用户提出首批产品需求。
- 使用场景：电脑上同时打开多个终端运行 AI Agent 或交互式命令，手机通过 SSH 远程查看、切换和操作这些终端。

## 关键功能点

- 电脑端 `attach` 跟踪普通终端会话，并自动拉起单例服务统一管理。
- 服务汇总终端 title、进程信息、会话状态，尽量识别标签页。
- 手机端使用 KMP + Compose，通过 SSH 连接电脑后访问 Attach 服务。
- 手机端主界面为服务器列表，右上角 `+` 新增服务器。
- 服务器列表 UI 参考 TermNext 截图：`docs/assets/ui-reference/termnext-server-list.jpeg`，采用分组、数量标识、卡片列表和快捷新增入口。
- 连接服务器后进入终端标签页界面，可查看终端画面、输入指令、处理确认交互。
- 底部提供 `ESC`、`Enter`、方向键等快捷输入按钮。

## 设计与实现

- 涉及模块：`PCServer/` Rust 电脑端；`MobileClient/` KMP + Compose 手机端。
- 核心流程：终端启动 `attach` → 单例服务汇总会话 → 手机 SSH 登录 → 查询服务 → 切换并操作终端。
- 重要约束：电脑可能有 40~50 个终端，性能、稳定性和低资源占用优先。
