# 功能记忆：CI

## 背景

- 需求来源：工程化中的“CI”。
- 使用场景：提交或 PR 时自动验证 Rust 格式、测试和 clippy。

## 关键功能点

- 新增 `.github/workflows/ci.yml`。
- CI 执行 `cargo fmt --all -- --check`。
- CI 执行 `cargo test -p attach`。
- CI 执行 `cargo clippy --all-targets --all-features -- -D warnings`。

## 设计与实现

- 涉及模块：`.github/workflows/ci.yml`。
- 核心流程：checkout → 安装 stable Rust → fmt/test/clippy。
- 重要约束：当前是 GitHub Actions 配置；如果实际托管只使用 Gitee，需要另接 Gitee CI。

## 验证方式

- 命令：`cargo fmt --all -- --check`
- 命令：`cargo test -p attach`
- 命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 结果：本地同等命令通过。

## 后续注意事项

- 发布包阶段可在 CI 上增加 release 构建和 artifact 上传。
