# 鸿蒙 App 全页面主题与对比度检查

## 背景

鸿蒙真机处于深色系统主题时，部分页面使用固定浅色背景，但文字、图标和输入控件仍继承系统深色主题的浅色前景，导致白底白字、按钮不可辨认。

## 目标

- 检查鸿蒙 App 当前全部可达页面及主要弹框的背景与前景对比度。
- 修复固定浅色界面在深色系统主题下的文字、图标、输入框和按钮可见性。
- 使用 Release 签名包覆盖安装到真机，逐页截图确认修复生效。

## 平台需求

- 平台：HarmonyOS ArkTS App（`MobileApp/harmonyApp/`）。
- 验收设备：已连接的 HUAWEI Pura 70。
- 验收主题：系统深色模式。

## 检查范围

- 服务器列表首页及空状态。
- 新增服务器、编辑服务器弹框。
- 设置页。
- 网络诊断页。
- SSH 终端页及工具栏。
- MUX 导航页、相关操作弹框和 MUX 终端页。
- 删除、复制等系统确认弹框。

## 关键规则

- 固定浅色背景的容器必须显式指定深色文字和图标颜色。
- 输入框必须显式指定文字色、占位色和背景色，不能混用系统主题默认值。
- 固定深色终端界面保持现有终端配色，不因本次修复改动 ANSI 色彩逻辑。
- 覆盖安装必须使用 `entry-default-signed.hap`，保留已有服务器配置和凭据。

## 非目标

- 不重做页面布局、导航结构或品牌视觉。
- 不新增完整的浅色/深色主题切换系统。
- 不修改 Rust SSH 与终端核心逻辑。

## 待澄清问题

- 无；本次以现有浅色业务页面与深色终端页面的设计方向为准。
