# 未连接成功时禁用 MUX 导航按钮

## 背景

SSH 终端页的 `MUX...` 导航需要依赖已建立的服务器会话。连接中或连接失败时提前点击没有可用的远端会话，应该保留入口位置但禁止操作。

## 目标

- Android、iOS、HarmonyOS 终端页在 SSH 连接成功前禁用 `MUX...`。
- 收到 `connectionState=connected` 后立即恢复按钮；失败、关闭或重新连接时再次禁用。
- 已从 MUX 导航进入的终端仍隐藏该按钮，不改变原有返回流程。

## 非目标

- 不改变 SSH 超时、重连或 MUX 列表加载逻辑。
- 不在未连接状态发起 `muxmirror` 查询或打开导航页。
