# SSH 终端页工具条与间距改造

## 背景

当前 SSH 终端页底部为"复制终端内容 + 发送按钮 + 单行快捷键栏"，间距偏大、快捷键不足（缺 HOME/END/PGUP/PGDN/DEL 等）、无修饰键能力、无独立粘贴/弹出键盘入口。物理键盘与直接输入改造验收通过后，按本需求重做底部工具区与页面间距。

## 前置条件

- 上一批改动（终端直接输入、物理键盘桥接、KeyboardOptions）在模拟器上人工验收通过后才开工。

## 目标

1. **间距**：顶部标题栏（服务器名 + ssh 信息 + 返回）整体上下边距缩小 50%；终端窗口与其他元素之间的上下间距缩小 50%。
2. **终端内选择复制**：终端窗口内文本可长按选择并复制（替代按钮式"复制终端内容"）。
3. **底部键盘工具条**：两行工具键，每个按键等宽等高；不同屏幕分辨率/宽度下按键平均分配整行宽度。
4. **工具条随键盘移动**：软键盘弹起/收起时工具条贴合键盘上沿跟随移动（imePadding），不遮挡、不跳动。
5. **第一行按键（10 个）**：`/ - : * | HOME ↑ END PGUP DEL`
6. **第二行按键（10 个）**：`ESC TAB PAST CTRL ALT ← ↓ → PGDN ⏏`
   - `⏏`：弹出/收起软键盘。
   - `PAST`：将剪贴板内容写入当前输入缓冲。
   - `CTRL`、`ALT`：修饰键，带 Check 状态；标签显示下划线，激活时高亮；效果等同于物理键盘上一直按住该修饰键（再次点击取消），作用于其后输入的按键。
7. **移除**"复制终端内容"按钮和"发送"按钮（发送依赖软键盘发送键/物理键盘 Enter）。
8. **键盘弹出与收起动画平滑、无闪烁**。

## 关键流程（实现要点，开工时细化）

- 符号键（`/ - : * |`）插入输入缓冲光标处；功能键（ESC/TAB/HOME/END/PGUP/PGDN/DEL/方向键）发送对应 ANSI 序列到 SSH 通道（HOME `\e[H` 或 `\e[1~`、END `\e[F` 或 `\e[4~`、PGUP `\e[5~`、PGDN `\e[6~`、DEL `\e[3~`，开工时以 xterm 为准）。
- CTRL/ALT 激活态：对后续字母键发送对应控制字符（Ctrl）或 ESC 前缀（Alt），现有快捷键栏的 CTRL/ALT 单次序列逻辑由激活态机制取代。
- 工具条两行用 `Row` + 等 weight 单元实现均分；按键等宽等高；高度统一。
- 工具条容器使用 `imePadding()` 贴合键盘；动画平滑通过避免在键盘动画期间触发整页重组/文本闪烁实现（开工时验证，必要时调整 cursor 闪烁与滚动动画）。

## 非目标

- 不改动顶部标题文字内容与返回逻辑。
- 不在工具条提供 Enter（发送）键。
- 本地终端页（LocalTerminalScreen）本次不改动。

- 已于 2026-07-18 确认：⏏ 用于切换软键盘弹出/收起；键盘弹出后图标上下翻转。
