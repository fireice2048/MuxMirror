# 项目流程规则需求

本文记录项目协作、记忆和复杂任务执行规则。

## 1. 需求记录

- [x] 每次用户输入新需求时，先把需求要点记录进需求文档，再开始实现。

## 2. 记忆系统

- [ ] 重大 Bug 修复后补充 `docs/memory/` 记忆文件，记录现象、根因、修复方案和预防措施。
- [ ] 典型踩坑后补充 `feedback` 类型记忆，记录坑点和避免方法。
- [ ] 同类错误反复出现 2 次及以上时补充 `feedback` 类型记忆，记录错误模式、触发条件和正确做法。
- [ ] 定期回顾记忆文件，更新或删除过期内容。

## 3. 复杂任务执行

- [x] 复杂任务先写计划文档。
- [x] 复杂任务同步维护可勾选的进度文档。
- [x] 每完成一个小里程碑提交一笔代码。
- [x] commit log 使用中文。
