## 逐按钮验收清单

- [x] `/` 插入当前输入缓冲光标处。
- [x] `-` 插入当前输入缓冲光标处。
- [x] `:` 插入当前输入缓冲光标处。
- [x] `*` 插入当前输入缓冲光标处。
- [x] `|` 插入当前输入缓冲光标处。
- [x] `HOME` 在本地输入存在时移动到行首；空输入时向远端发送 Home。
- [x] `↑` 可调出上一条远端历史命令。
- [x] `END` 在本地输入存在时移动到行尾；空输入时向远端发送 End。
- [x] `PGUP` 本地向上翻动一页终端输出。
- [x] `DEL` 删除光标后的字符；无本地可删字符时发送远端 Delete。
- [x] `ESC` 发送 Escape。
- [x] `TAB` 在无修饰状态下进入输入缓冲，并能随命令发送。
- [x] `PAST` 将剪贴板文本插入当前光标处。
- [x] `CTRL` 可锁定/解除、视觉状态明确，并作用于后续输入或功能键。
- [x] `ALT` 可锁定/解除、视觉状态明确，并作用于后续输入或功能键。
- [x] `←` 在本地输入存在时向左移动光标；空输入时发送远端 Left。
- [x] `↓` 可向下浏览远端历史命令。
- [x] `→` 在本地输入存在时向右移动光标；空输入时发送远端 Right。
- [x] `PGDN` 本地向下翻动一页终端输出。
- [x] `⏏` 可弹出/收起软键盘，弹出时图标沿垂直方向翻转，工具条贴合键盘上沿。
