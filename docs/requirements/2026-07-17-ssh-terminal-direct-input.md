# SSH 终端页直接输入改造

## 背景

当前 SSH 终端页底部使用独立的多行输入框 + 火箭图标按钮发送命令，与真实终端体验不一致，且输入区域占用页面空间较大。

## 目标

1. 去掉底部输入框：终端窗口内直接显示闪烁光标并接收软键盘输入；点击终端区域唤起软键盘，输入法发送键（IME Send）直接发送当前行。
2. 发送按钮移到"复制终端内容"同一行右侧、靠右对齐，文案改为"发送"。
3. 页面四周外边距缩小到原来的 30%（16.dp → 4.8.dp）。

## 平台需求

- 主要验证平台：HarmonyOS 模拟器。
- 改动位于 `composeUI` commonMain 共享 UI，Android/iOS 同步生效。

## 关键流程

- 终端区域内放置 1.dp 近透明 `BasicTextField` 作为软键盘输入入口；点击终端区域请求其焦点以唤起键盘。
- 输入缓冲渲染在终端输出文本末尾，光标（▌，闪烁）位于当前编辑位置，随输入自动滚动到底部。
- "发送"按钮或 IME Send：将当前输入行加 `\r` 写入 SSH 通道并清空缓冲；缓冲为空时按钮禁用。
- 快捷键栏符号键（`_ - + / * TAB`）仍插入到输入缓冲光标处，其余快捷键直接写入 SSH 通道。

## 非目标

- 不实现全屏 TUI 程序（vim、top 等）所需的终端模拟能力。
- 不做逐字符实时发送，保持行缓冲发送模型。
- 本地终端页（`LocalTerminalScreen`）本次不改动。

## 待澄清问题

- 无。
