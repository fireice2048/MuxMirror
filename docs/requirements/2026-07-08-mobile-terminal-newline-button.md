# Mobile 终端输入换行按钮需求

## 背景

移动端终端页面底部输入栏用于输入命令或提示词。手机软键盘在终端场景中经常将回车映射为发送、执行或隐藏键盘，导致用户难以在输入框中插入字面换行。截图参考显示当前底部输入提示词区域空间有限，需要一个紧凑的显式换行入口。

## 目标

- 在 Mobile 终端页面底部输入提示词栏增加一个 `↵` 换行按钮。
- 用户点击 `↵` 时，在当前光标位置插入一个字面换行字符 `\n`。
- 插入换行不触发发送、不执行远端命令、不改变当前终端会话连接状态。
- 输入框保留焦点，并将光标移动到新插入换行之后。

## 平台需求

- 移动端计划使用 KMP + Compose 实现；后续实现应优先放在共享 Compose UI 层。
- `↵` 按钮应适配手机窄屏，放在底部输入栏右侧或发送按钮附近。
- 按钮应至少提供无障碍说明，例如 `插入换行`。
- 软键盘打开时按钮仍应可见或可轻松触达。

## 关键流程

1. 用户进入终端会话页面。
2. 用户在底部输入提示词栏输入多行内容的第一行。
3. 用户点击 `↵` 按钮。
4. App 在当前光标处插入 `\n`，输入框显示下一行。
5. 用户继续输入后，通过既有发送动作提交完整多行内容。

## 非目标

- 本需求不改变 PC 端 `send_input` 协议。
- 本需求不新增独立的“发送多行命令”协议。
- 本需求不修改终端快捷键栏的其他按键含义。
- 本需求不要求现在补齐完整 Mobile Gradle 工程。

## 待澄清问题

- 终端页面最终是否同时存在 `发送` 按钮和键盘回车发送行为。
- 多行输入框的最大高度、滚动行为和是否自动展开。
- 当用户连接真实 shell 时，发送多行内容是否一次性写入，还是按行分批写入。
