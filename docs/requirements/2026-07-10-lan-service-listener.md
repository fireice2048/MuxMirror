# Attach 局域网服务监听需求

## 背景

移动端模拟器通过电脑局域网地址访问 Attach 服务。服务端不得把某台电脑的网卡 IP 写入代码或默认配置。

## 目标

- 本机 Attach CLI 继续通过回环地址访问服务。
- 服务可独立绑定通配监听地址，使当前电脑任意可用局域网 IP 都能被移动端访问。
- 监听地址与本机客户端连接地址均支持环境变量和配置文件设置。

## 关键流程

1. `ATTACH_SERVICE_ADDR` / `service_addr` 表示 Attach CLI 连接服务的地址。
2. `ATTACH_LISTEN_ADDR` / `listen_addr` 表示服务进程监听的地址；未设置时沿用 `service_addr`，保持现有行为。
3. 局域网部署使用 `127.0.0.1:<port>` 作为服务连接地址、`0.0.0.0:<port>` 作为监听地址；移动端填写当前电脑的实际局域网 IP 和同一端口。

## 非目标

- 本次不增加 mDNS、局域网扫描或自动发现。
- 不改变现有鉴权与协议。
