# Attach 终端增强工具需求文档

## 背景

用户希望在电脑上打开多个终端并运行 AI Agent 或其他交互式命令时，可以通过手机远程查看、切换和操作这些终端会话。传统 tmux 需要预先进入会话，且移动网络断连后需要手动重连；Attach 希望降低使用门槛，让普通终端启动后即可被统一管理和远程操作。

## 项目目标

- 提供跨平台电脑端终端增强工具 `attach`，支持 macOS、Windows、Linux。
- 手机端通过 SSH 连接电脑，再连接电脑上的 Attach 服务，查看和操作已跟踪终端。
- 支持大量终端实例汇总管理，目标场景为电脑上同时开启 40~50 个终端。
- 优先保证性能、稳定性和低资源占用。

## 电脑端需求

1. 用户启动终端后执行 `attach`，可手动运行，也可放入 `~/.zshrc` 等 shell 启动脚本自动运行。
2. 每个 `attach` 进程跟踪当前终端会话。
3. `attach` 自动拉起本机服务；服务全局只需启动一次。
4. 服务汇总管理所有终端实例，记录终端 title、进程信息和会话状态。
5. 如果平台能力允许，尽量识别终端标签页信息。
6. 电脑端使用 Rust 开发，设计上参考 tmux 的终端复用、会话管理、detach/reattach 能力，但目标是增强普通终端接入体验。

## 手机端需求

1. 手机端 App 使用 KMP + Compose 跨平台开发。
2. App 通过 SSH 协议连接电脑；非内网场景由用户自行配置 VPN，不属于 App 职责。
3. 主界面直接展示服务器列表，右上角提供 `+` 按钮用于新增服务器。
4. 配置正确后，点击服务器列表项，直接连接服务器并进入终端显示标签页界面。
5. 连接后查询电脑 Attach 服务，展示可用终端进程和标签页。
6. 使用简洁 UI 展示 Attach 进程，并支持通过标签页切换到指定终端。
7. 当前页面显示电脑终端视图信息。
8. 如果终端出现需要用户选择或确认的交互事项，手机端必须支持操作。
9. 手机端必须支持输入指令。
10. 屏幕底部提供快捷输入按钮，例如 `ESC`、`Enter`、上下左右箭头等；快捷键体验可参考 TermNext 类 SSH 终端 App。
11. UI 应具备现代 App 体验，操作顺滑，适合手机软键盘交互。

## 手机端 UI 参考

参考截图：`docs/assets/ui-reference/termnext-server-list.jpeg`。

服务器列表页可参考 TermNext 的信息架构和视觉风格：顶部为大标题“服务器列表”，右上角使用圆形 `+` 按钮新增服务器；正文按分组展示，例如“默认分组”，分组右侧显示服务器数量和展开/收起箭头；服务器以卡片形式展示，包含服务器图标、名称和连接方式/用户名摘要，例如 `ssh, xpeng`。Attach Mobile 的主界面应保持类似的简洁入口，用户打开 App 后优先看到服务器列表，点击卡片即可连接并进入终端标签页界面。

## 关键体验流程

1. 电脑端用户打开多个终端。
2. 每个终端自动或手动运行 `attach`。
3. Attach 本机服务持续汇总终端会话。
4. 手机端打开 App，主界面展示服务器列表。
5. 用户点击服务器后通过 SSH 登录电脑。
6. App 连接 Attach 服务并展示终端/标签页列表。
7. 用户切换到某个终端，查看画面、输入命令、处理确认选择。

## 非目标

- 不负责公网穿透或 VPN 配置。
- 不要求替代 SSH 协议本身。
- 第一阶段不强制实现所有终端 App 的标签页识别；无法识别时以终端进程或会话为主。

## 待澄清问题

- 电脑端 Attach 服务与手机端之间的本地协议格式。
- SSH 登录后如何安全发现和连接 Attach 服务。
- Windows 终端、macOS Terminal/iTerm2、Linux 常见终端的标签页识别能力差异。
- 终端画面同步是基于 PTY 捕获、终端缓冲区镜像，还是通过 attach 代理启动命令实现。
- 手机端是否需要支持多服务器并发连接和后台保活。

## 当前实现状态

- 已创建 Cargo workspace 和 `PCServer/attach` Rust CLI 原型。
- 已实现 `attach track`、`attach daemon`、`attach register`、`attach service`、`attach list`、`attach shutdown` 基础命令。
- 已实现 `attach auth-info`，Mobile 端可通过 SSH 获取本机服务 endpoint、token、user 和协议版本。
- 已实现 `attach hello`，Mobile 端连接服务后可查询协议版本和服务能力。
- 已实现本机 Attach 服务原型，支持会话注册、心跳续约、过期清理、列表查询、会话连接元数据返回、managed PTY 输出读取、输入写入、窗口调整、列表接入、重复 `track` 去重、token 校验、结构化错误码、会话操作请求骨架和优雅退出。
- 已创建 `MobileClient/` KMP + Compose 目录占位和移动端说明文档。
- 尚未实现普通被跟踪终端画面同步、输入转发、标签页识别和完整移动端工程配置。
