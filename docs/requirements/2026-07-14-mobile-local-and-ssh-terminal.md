# 移动端本地终端与 SSH 直连终端需求

## 背景

当前移动端首页展示已保存的服务器，但点击服务器后仍需经过终端窗口列表。用户需要更直接地进入远程终端，并希望在首页提供一个可执行本机命令的本地终端入口。

## 目标

- 首页左下角提供 `LOCAL` 按钮，点击后打开平台对应的本地工具页。
- Android 和 iOS 的本地工具页为 Local Shell，使用黑色终端画布，支持输入并执行本机 shell 指令。
- HarmonyOS 的本地工具页为“网络诊断”，不执行任意 shell 命令；支持对 IPv4 地址和端口进行 TCP 连通性检测。
- 点击服务器列表项后直接进入新的 `SSHPage`，不再显示终端窗口列表。
- `SSHPage` 首先显示加载动画并建立 SSH 连接；连接成功后显示远程终端内容，并可继续输入控制。
- 鸿蒙模拟器中的物理键盘必须可在已聚焦的终端输入框中输入；浏览器可输入而 App 不可输入视为阻断缺陷。
- 终端输出支持按文本选择后复制，且键盘弹出时底部输入栏必须避让，不得被遮挡。

## 平台需求

- 共享 Compose UI 必须继续支持 Android、iOS 和 HarmonyOS。
- 本地命令执行由各平台提供平台实现；iOS 模拟器使用 `/bin/sh -lc`，仅用于开发机本地终端。
- HarmonyOS 普通应用不能执行 `/system/bin/sh`、`popen` 或 ICMP `ping`；网络诊断只能使用应用权限允许的 TCP socket 能力。
- 新终端页直接使用标准 SSH 协议，沿用当前服务器配置中的地址、端口、用户名和密码；不得调用 Attach TCP/JSON 协议，也不得在日志中输出密码。
- 本阶段优先完成 HarmonyOS；Android、iOS 的标准 SSH 平台实现后续补齐，共享 Compose 页面保持平台实现可替换。
- HarmonyOS SSH 使用 libssh2 建立会话、密码认证并打开 `xterm-256color` PTY；加密后端使用 mbedTLS。

## 关键流程

1. 用户在首页点击 `LOCAL`：Android/iOS 进入 Local Shell；HarmonyOS 进入网络诊断，输入 `tcp <IPv4> [port]` 后显示连接结果。
2. 用户点击服务器列表项，进入 `SSHPage`，加载状态展示转圈动画与连接提示。
3. 连接成功后，`SSHPage` 打开远程交互式 shell 并展示 PTY 输出；输入栏和快捷键直接写入 SSH channel。
4. 连接失败时显示原因和返回首页操作，不进入旧的窗口导航页。
5. 用户可选择终端输出文本并复制到系统剪贴板；点击终端输入框后，无论软键盘还是物理键盘输入，输入栏始终可见。

## 非目标

- 本次不实现完整 VT100/ANSI 终端渲染器、SSH 文件传输或多会话选择页。
- Local Shell 不保证常驻交互式进程的 stdin 流式管理；每次发送执行一条 shell 命令。
- 不更改 PCServer 网络协议。
- 本阶段不通过 SSH 再发现或连接 Attach 服务，不展示 Attach 窗口或标签页。

## 待澄清问题

- 首版只支持密码认证；主机密钥持久化与公钥认证留待后续安全增强。
