# Mobile 终端输入换行按钮人工验收

## 前置条件

- Mobile 终端页面已经实现底部输入提示词栏。
- 终端页面已经接入一个可输入的 Attach 会话或本地预览状态。
- 页面底部输入栏展示 `↵` 按钮。

## 验收场景

### 场景 1：空输入插入换行

1. 进入终端页面。
2. 确认底部输入栏为空。
3. 点击 `↵`。

通过标准：输入栏进入多行状态，内容为单个换行；不会发送任何输入到远端会话。

### 场景 2：文本末尾插入换行

1. 在输入栏输入 `line1`。
2. 将光标保持在文本末尾。
3. 点击 `↵`。
4. 继续输入 `line2`。

通过标准：输入栏显示两行内容，第一行为 `line1`，第二行为 `line2`；远端终端未因点击 `↵` 单独执行命令。

### 场景 3：文本中间插入换行

1. 在输入栏输入 `abcdef`。
2. 将光标移动到 `abc` 和 `def` 之间。
3. 点击 `↵`。

通过标准：输入栏内容变为 `abc\ndef`，光标位于换行之后、`def` 之前。

### 场景 4：焦点与键盘保持

1. 打开软键盘并在输入栏输入任意文本。
2. 点击 `↵`。

通过标准：输入栏仍处于可继续输入状态；软键盘不应因为点击 `↵` 而被强制关闭。

### 场景 5：窄屏可用性

1. 使用截图相近的窄屏手机尺寸打开终端页面。
2. 聚焦输入栏并打开软键盘。

通过标准：`↵` 按钮仍可见或可触达，不遮挡主要输入内容，不与底部快捷键栏严重重叠。
