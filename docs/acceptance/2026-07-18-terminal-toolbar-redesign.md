# SSH 终端工具条人工验收

## 环境

- HarmonyOS API 20+ 手机模拟器。
- 已保存可成功连接的 SSH 服务器配置。
- 必须发布最新 KMM `libkn.so`、清理构建并安装 `entry-default-signed.hap`。

## 验收步骤

1. 打开服务器并进入 SSH 终端，确认标题区和终端上下外间距明显缩小，页面不再显示“复制终端内容”和“发送”。
2. 长按终端已有输出，拖动选择柄并从系统菜单复制；在其它文本框粘贴确认内容一致。
3. 横向或在不同尺寸模拟器上观察工具条，确认两行各 10 个按钮、按钮等宽等高且无横向滚动：
   - 第一行：`/ - : * | HOME ↑ END PGUP DEL`
   - 第二行：`ESC TAB PAST CTRL ALT ← ↓ → PGDN ⏏`
4. 点击 PAST，确认剪贴板文字插入当前输入光标位置。
5. 点击 CTRL，确认标签有下划线且按钮保持高亮；输入 `c`，确认远端收到 Ctrl+C；再次点击 CTRL 后取消高亮。ALT 以同样方式验证锁定和取消。
6. 验证 HOME/END/←/→ 编辑本地输入光标，↑/↓ 操作 shell 历史，PGUP/PGDN 翻动终端输出，DEL 删除光标后的字符。
7. 在键盘收起状态点击 ⏏，确认键盘平滑弹出、工具条贴住键盘上沿且图标上下翻转；再次点击确认键盘平滑收起、工具条回到底部且图标复原。
8. 连续弹出/收起键盘 5 次，观察终端、工具条和光标，无明显闪白、重叠或跳帧。

## 通过标准

- 以上步骤全部通过，并保留键盘弹出和收起两种状态的截图。
- 不能仅以构建或安装成功作为验收通过证据。
